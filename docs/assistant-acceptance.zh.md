# AI 助手验收

[English](assistant-acceptance.md) | 中文

## 摘要

验收在隔离的集成工作区中使用合成文档、Node 24.15.0 和版本显示为 0.2.1-rc.2 的 Harness 产物。已测试的 Web 实例为 `http://127.0.0.1:59190/`；端口 58358 上的原配置未改变。安装包依赖从注册表独立安装。浏览器使用已配置的 DeepSeek-V4.1-Flash 模型（`deepseek-account` / `deepseek-flash`，high 推理强度）。未要求新增模型凭据。

已执行范围内的本地集成验收通过，包括恢复及 Host 销毁修复后重新运行的双入口真实模型流程。声明的 Harness 依赖版本不能证明已发布运行时支持所有已测试交互：Web 与 CLI 验收使用本地构建的 Harness 产物。发布需要支持相关功能且经过验证的 Harness 发行产物，以及明确批准。

<a id="replay-limits"></a>
## 回放限制

原有图片字节脱敏夹具保持完整。另有三个在最终生命周期修复之前录制并整理的真实回合，覆盖插件入口 2 → 3、普通入口 35 → 36 和选择性撤销 7 → 8。这些录制未改动，并在最终安装候选版本上回放；重新执行的浏览器／模型验证在上文单独报告。它们分别使用精确种子，并非对手工浏览器历史的连续回放。插件用例保留被拒绝的错误编辑。撤销种子包含真实提案标识和之后的手工图片修改。

仅保留工具／文本流、工具参数／结果及必要生命周期事件。私有推理、账户／用量／投递元数据及无关输入被排除；最终文本仅保留录制的完成标记。版本 4 引用重新映射，回合从 1 重新编号，主机路径替换为明确的夹具标记。保存内容与预期错误仍接受断言。

公开 headless 运行器拒绝带有 Web Preset 的 Session。获准的测试映射会断言原 `standard` Preset，将原始创建元数据保留在夹具中，仅从临时 headless 初始化中移除 `agentPreset` 并映射工作目录。实际 Session 标识、绑定及文档种子不变。这验证已安装工具行为，不验证相同 Preset 或完整 Web Session 续接。真实 Standard-Preset 行为由上述独立浏览器运行覆盖。

## 未执行的检查

最终浏览器验收未执行永久 GUI 删除、四种导入格式的原生图片／文件选择器、系统下载目标选择、交互创建嵌套分组、实体修饰键滚轮、原生中文输入法及系统减弱动态效果切换。存储／解析／渲染、画布、输入法组合／滚轮与减弱动态效果测试补充这些项目，但不能证明未执行的系统交互。未运行 Desktop、所有操作系统和穷尽覆盖率。未提交 GUI PR 或 GIF，未推送或发布。

公共侧栏 API 无法重建完全发生在可观察采样之间的短暂切走再切回。
